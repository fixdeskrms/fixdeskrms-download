# FixDesk RMS

โปรแกรมบริหารร้านซ่อม จำนำ และขายหน้าร้าน สำหรับ Windows
รับเครื่อง พิมพ์ใบรับงาน แจ้งลูกค้าผ่าน LINE ติดตามสถานะ สต็อก ขาย ผ่อน และรายงาน ในโปรแกรมเดียว

## ดาวน์โหลด

ไปที่หน้า [Releases](../../releases/latest) แล้วเลือกไฟล์ `FixDeskRMS_Setup_x.x.x.exe`

## ความต้องการของระบบ

- Windows 64 บิต
- เครื่องพิมพ์ใบเสร็จ 80mm (ถ้าต้องการพิมพ์ใบรับงาน)
- ตัวติดตั้งแนบ WebView2 Runtime มาให้แล้ว

## วิธีติดตั้ง

1. ดาวน์โหลดไฟล์ติดตั้ง แล้วดับเบิลคลิก
2. ถ้า Windows ขึ้นหน้าต่าง "Windows protected your PC" ให้กด **ข้อมูลเพิ่มเติม** แล้วกด **เรียกใช้อยู่ดี** (ตัวติดตั้งยังไม่ได้ลงนามดิจิทัล)
3. ทำตามขั้นตอนบนหน้าจอจนเสร็จ แล้วเปิดโปรแกรม
4. ใช้งานเต็มรูปแบบต้องมีคีย์ลิขสิทธิ์ ติดต่อผู้พัฒนาเพื่อขอคีย์
